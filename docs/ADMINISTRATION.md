# 自助练习的施测流程与中断处理

更新：2026-10-21。流程版本：`self-guided-2026-10-21-v1`。题库与 IQ 模型版本仍分别记录，流程改进不表示 IQ 已获得实证校准。

## 资料依据

本轮查阅了 [ITC/ATP《数字测评指南》1.1 版（2025 年 7 月）](https://www.intestcom.org/upload/media-library/tba-guidelines-ver-11-july-2025-1754044782Z3vV9.pdf)。1.14、1.15 节讨论操作教程、示例和清晰指导；3.36、4.21 节讨论中断监测与记录；4.23 节指出缺失成绩的推算需要实证研究支持。

[Pearson 的 WAIS-5 远程施测说明](https://www.pearsonassessments.com/content/dam/school/global/clinical/us/assets/telepractice/guidance-documents/telepractice-and-the-wais-5.pdf)说明媒介和施测条件需要专业判断，远程程序存在对标准施测的偏离。本应用的屏幕文字、自助操作和视觉数字呈现不能由此视为正式 WAIS-5 施测。

以下是本应用采用的具体设计，并非上述资料规定的官方韦氏规则。没有将其他人群或其他题库的常模套入本题库，也没有声称符合整份指南的所有要求。

## 完整流程

1. 首页阅读结果解释、填写年龄；进入完整练习或选择三题单项练习。
2. 每个分测验显示其目的、操作方式、题量、每题限时和一题独立的操作示例。说明和示例不计时，也不计分。
3. 示例可重试并给出解释。选择题确认点击操作；数字题确认完整序列输入及升序规则。数字说明同时解释顺序、逆序与升序。
4. 示例完成后，由用户点击“开始本分测验”。此时才开始第一个计分项目的计时。每个新分测验都重复此流程，可在说明页休息。
5. 计分题继续使用预先定义的评分规则、单调时钟截止时刻与防重复提交检查，不即时显示正确答案。计分题数字刺激只显示一次。
6. 全部项目处理结束后显示原始成绩、过程记录、逐题解析。完整且无中断的作答仍可按模型门槛生成明确标注为未校准的量表分剖面。

示例由本项目自编，保存在独立模型中，不占用 120 道计分题，不写入逐题成绩或练习最佳分。示例反馈用于熟悉交互，并不证明测量效度。数字示例为不计时的可见输入练习，不模拟完整的记忆测量。

## 中断规则

应用在计分题的刺激或作答阶段失去前台活动状态时，立即进入中断页并停止推进项目。锁屏、切换应用、系统来电或控制中心等都可能触发；系统事件本身不用于判断作弊、努力程度或能力。

- 中断时隐藏当前题，保留此前答案；后台不连续超时并消耗后续题目。
- 回到前台后等待“继续下一题”确认。已曝光的受影响题不重播、不补答，标记 `interrupted`，答案为空；这不表示回答错误。
- 中断题的 `score=0` 仅为旧原始分累加结构的占位值。汇总时将它的满分从分母排除，并在逐题报告标为“未计分”。其余题超时仍按零分处理。
- 若失去前台时已经到达该题截止时刻，仍按超时计零分并保留分母，不将已经发生的超时改为缺项；也会等待用户确认后才呈现下一题。
- 得分率只描述其余计分题。所有项目都中断时显示无计分成绩，不将空分母解释为真实的 0% 表现。
- 存在任何中断题时，不填补缺失成绩，不生成 IQ 估算，也不更新三题单项练习的次数或最佳成绩。这是本应用的保守输出策略，不是已经验证的效度界限。
- 说明、示例、分测验间休息期间失去前台不计为计分项目中断，返回后可继续准备。
- 同一受影响题在确认继续前多次离开前台合并为一次项目中断，累加系统报告的非活动时长。

中断题的 `elapsedSeconds` 保存中断前已经过的作答时间，刺激阶段中断时为零。中断事件另存阶段和非活动时长。恢复确认的等待时间不加入题目作答时长，也不会替后续题提前启动计时。

## 保存与兼容

完整记录新增可选 `administration`，保存流程版本、已完成示例的分测验、开始时本机是否已有练习记录，以及逐次项目中断的题号、阶段、非活动时长。题库版本、IQ 模型版本、逐题答案继续分别保存。历史页会提示中断记录未生成 IQ。

旧记录没有 `administration` 时按原格式读取，不补造流程记录。中断完整练习仍保存可用成绩；关闭未结束的三题练习会清理运行状态，不写入最佳分。完整练习另支持主动结束并保存已有项目，以及历史题目快照，见 [历史与结束流程](HISTORY_AND_EXIT.md)。记录保存在本机，没有添加自动上传或外发功能。

目前过程记录仅覆盖系统提供的前台状态，无法检测环境噪声、外部协助、纸笔或其他设备。没有添加应用被系统终止后的断点续测；应用终止时未完成作答不会自动恢复。后续如引入恢复，必须区分已经曝光和未曝光的项目。

## 验证与后续校准

自动测试覆盖说明阶段不计时、不计分、跨分测验重新准备、正常计分不变、中断不推进后台项目、数字刺激不重播、重复事件合并、中断项目分母排除、全部中断、记录兼容与完整 UI 流程。

这些验证证明程序行为。要评价 IQ 精度，仍需真实样本与同一参与者的正式测验配对数据；参见 [IQ 算法与校准路径](IQ_ESTIMATION.md)。在题目参数、维度和停止标准尚未经过校准时，本项目继续完整呈现固定题库，不将自适应选题或快速停测包装为精度改进。
