# 参与说明（试采集）

面向参与本应用练习并同意提供作答数据的人。这份说明可以直接转发给参与者。

## 这是什么

这是一个自编的认知练习，用来改进练习本身的题目参数与分数换算。
**它不是正式的智力测验**，结果不能用于升学、招聘、医疗或任何需要正式评估的场合。
正式评估请找有资质的心理专业人员。

## 你需要做什么

1. 安装应用（iPhone，iOS 17 或更高）
2. 首页选择练习体系：
   - **韦氏风格练习**：10 个分测验共 120 题，约需 25–35 分钟
   - **瑞文推理练习**：12 题，约需 5 分钟
3. 首页填入年龄（建议填，用于分析年龄的影响；不填也能测）
4. 完整做完，中途尽量不要退出
5. 做完后在结果页点「导出 JSON」；也可以回到首页的「历史成绩」批量导出

## 一轮测一个题组

如果你打算做多轮，**每轮固定用同一个题组**（A 或 B）。
应用会自动避开你做过的题，所以多轮之间题目不同——这是刻意的，
目的是避免"看过解析再做同一题"让分数虚高。

不同题组之间的分数不能直接比较（两组题目难度未做等值验证）。

## 我们收集什么

- 每道题的**你的作答**、对错、用时
- 完成状态、开始时的年龄、题组、练习的难度
- 逐题的题目与解析快照

## 我们不收集什么

- 姓名、账号、设备标识、位置、通讯录
- 应用本身不采集这些，导出文件里也没有

## 数据的用途与公开范围

- 用途：估计题目难度参数、标定分数换算、检查题目是否存在歧义
- **原始逐题数据不会公开**。公开的只有汇总后的统计结果
- 分析结果可以写进报告或公开，用来改进这个练习

## 你可以退出

- 随时可以在历史页删除自己的记录
- 退出后请一并删除你导出的 JSON 文件
- 参与完全自愿，不参与不会影响你使用这个练习

## 关于结果

练习会给出一个"全量表分"和一个区间。这个分数**未经人群常模校准**，
只表示你这次在本题库里的相对位置，不能与正式韦氏分数比较，也不能理解为你的智商。

如果你对结果有疑问，最常见的解释是：**题库偏难**——按现有参数，
被判为"平均水平"需要答对约 82% 的题。这个数字来自参数设定，不是你的问题。
