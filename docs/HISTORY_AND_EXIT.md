# 未校准结果、历史详情和提前结束

更新：2026-10-21。

## 题组之间的分数不可比

A/B 两组的题目内容不同，难度阈值也大多各自设定（见 [IQ 估算说明](IQ_ESTIMATION.md)），
既没有等值证据，两组分数也不能直接比较。历史页在当前筛选结果包含两个题组时，会显式提示这一点；
单条记录会显示所属题组与「题组尚未等值」。不能据两组的分数高低判断哪一题组更难。

## 瑞文模块的结果说明

该模块是包含数字、语言、逻辑及符号规律的自编推理练习，不是官方 Raven's 量表。本轮保留正常完成后的数值估算，改为明确显示“实验性 IQ 估算 / 未校准”，移除人群百分位、全球排名、能力高低评语与经验年龄加分。

结果同时给出 95% 估计区间：每轮只有 12 题，正确比例本身的抽样误差很大，区间按 Wilson 得分区间换算到 IQ 量尺（正态近似在全错或全对时会退化成零宽区间，Wilson 不会）。因此瑞文的点估计尤其不应被当作精确测量。

新模型版本为 `raven-heuristic-v2`，题库版本为 `raven-practice-2026-10-21-v2`。映射仍是经验假设：

```
IQ估算 = round(100 + (正确题数 / 总题数 - 该难度经验平均得分率) / 0.20 × 15)
显示边界：55...145
```

经验平均得分率分别为初级 0.70、中级 0.55、高级 0.40，并非实测常模。12 题条件下，答对一题带来的未截断变化约为 6.25 分；显示为整数不意味着达到 1 分精度。边界也不是已经验证的测量范围。新版本没有更接近正式 IQ 的实证证据。

新估算单独保存为 `ravenEstimate`，包含模型/题库版本和 `ageAdjusted=false`；正式 `iq`、`percentile` 字段不再填入。年龄和难度在开始时固定。旧记录原始数据保留，旧公式的 IQ 不再展示为有效估算；首页仅保留原始分最佳成绩。历史页不再汇总不同模型、题库和难度的 IQ 均值、最高分或混合趋势。

## 历史详情

新完整记录和提前结束记录保存 `reviewItems`，包括当次题干、实际选项及评分、答案、满分答案、得分、解析、状态和用时。数字回忆另存原始刺激序列、回忆规则和实际呈现时长，不保存未展示的备选项。之后的题库更新不改变这些历史快照，也不自动重算旧成绩。

历史列表可打开“记录详情”，查看原始分、开始时年龄、完成状态、A/B 题组、模型/题库/流程版本及逐题内容。旧记录没有题目快照时只显示已保存的内容，不借用当前题库补造当时的题干或解析。旧韦氏记录仍可查看逐题已保存的答案和分值。

## 提前结束

完整推理练习和韦氏练习在说明、答题或中断页面提供“结束并保存已答题”。点击后立即停止本轮推进，不需要先答完所有项目。

- 没有任何已记录项目时回到首页，不创建空历史。
- 有已记录项目但未处理完全部项目时，保存 `completion=endedEarly`、原计划题量和已有题目快照。只展示已记录项目的成绩；未提交及未开始的项目不计分，不展示解析。
- 点击结束时当前题已达到截止时刻，仍记录该题超时，不把超时消除。提交后的反馈阶段结束则保留已提交答案，不重复计分。
- 韦氏待确认的中断项目会保留中断状态与过程记录。中断题继续排除出得分率分母。
- 未完成记录不生成 IQ，也不更新最佳成绩。若全部项目已提交或处理完，只是在最后反馈阶段点击结束，则按完成保存。
- 多次点击结束或结束后迟到的计时回调不会重复保存。
- 三题单项练习的“关闭”立即清理运行状态并离开；未完成的单项练习不写入完整历史或最佳成绩。

主动结束会保留已答内容，仍没有实现应用被系统终止后的断点恢复。历史已改为逐条文件保存，支持旧数据迁移、损坏项隔离、保存失败重试以及用户控制的导出，见 [历史保存与导出](HISTORY_STORAGE.md)。
