# 历史保存、筛选与导出

更新：2026-10-21。

## 保存和旧数据迁移

历史改为保存在本机 Application Support 的 `IQTestHistory` 中。`records/<UUID>.json` 每个文件对应一轮完整或提前结束的练习；新成绩独立原子写入，不再把所有题目快照一起重写到偏好设置。

首次读取会迁移原 `UserDefaults.testRecords`：

1. 将原始字节原样保存为 `legacy-backup.json`。
2. 逐条解码旧数组，无法解码或题次 UUID 重复的条目留在原始备份中，记录异常数量。
3. 为缺少 UUID 的旧记录分配一次题次标识，将准备好的内容写入 `migration-prepared.json`。
4. 逐条保存成绩；全部成功后写入 `index.json` 提交迁移。若中途失败，下次继续使用准备文件中的 UUID，不重建题次。

已迁移后不会反复从旧偏好设置导入。旧原始备份和准备文件保留，直到用户清空全部历史和备份。旧记录缺失的题干、过程或题组不由当前题库补造。

新历史中某个文件无法解码或题次与文件名不匹配时，历史页会提示异常数量，同时展示其余可读记录；异常文件仍保留。整个旧数组或索引无法读取时明确显示错误，不伪装成“没有历史”，也不以空数组覆盖。未知的索引格式版本会阻止继续写入。

## 保存失败和重试

两种完整练习都在结束时固定一份成绩，包括 UUID、日期、题组、答案快照和模型结果。保存失败会显示“本次记录尚未保存”和重试入口，并可先导出这份成绩。重试使用同一份快照，不重新评分；成功后继续点击重试也不会重复写入。已存在的相同题次只有内容完全相同时才视作已保存，内容冲突或损坏时保留原文件并报错。

瑞文最佳原始分在完整记录成功保存后更新。保存失败或提前结束不提前更新最佳成绩。未保存时返回首页或重新开始会先确认放弃；取消会继续保留当前结果。尚未保存的结果保存在本轮内存中，系统终止应用仍可能使其丢失。本轮没有实现正在作答过程的断点恢复。

## 查阅和移除

历史页可组合筛选模块与完成状态，按时间从新到旧显示。统计和正常导出仅针对当前筛选结果，不汇总 IQ 均值或混合能力趋势。

记录详情的“记录操作”可从活动历史移除单条记录；如有旧版迁移备份，确认框会说明备份仍保留。即使所有活动记录都已移除，原始备份仍可导出或再次清理。工具栏“清空”会再次确认清除全部记录和迁移备份，作用范围不受筛选影响；清理失败会报告错误并重新读取实际状态。

## 用户控制的 JSON 导出

结果页可导出本轮已固定的成绩，历史页可导出当前筛选结果，详情页可导出该条记录。按钮打开系统文件保存界面，由用户选择位置；不自动上传或发送。

正常文件含 `formatVersion=1`、ISO 8601 的 `exportedAt`、解释说明和 `records` 数组。记录保留原始分、完成状态、题组、年龄、题目快照以及题库、模型和流程版本；韦氏记录另存 `wechslerProfile`（量表分剖面）与 `iqEstimate`（单参数模型结果）。导出不重算成绩。旧 `iq`/`percentile` 字段只作为原始档案保留，文件说明明确其不能当作有效标准分；量表分剖面与实验性 IQ 仍未校准，A/B 题组仍未等值。

“导出原始备份”生成单独的 `kind=raw-history-backup` JSON，`files` 字典将各文件的原始字节以 Base64 保存。损坏 JSON 也无需先解码即可保留；这些数据供核对和恢复使用，不自动导入或修复评分。

## 验证范围

测试使用独立临时目录和偏好设置域，覆盖正常落盘、重复重试、同题次冲突、旧数组中部分损坏、整个旧数组损坏、缺失 UUID、迁移写到中途失败、个别文件损坏、未知索引版本、不可用存储、移除/清空后不重新导入、原始备份导出，以及筛选和正常导出字段保留。

答题引擎测试覆盖两种练习保存失败后重试复用同题次和快照，以及保存成功后才更新瑞文最佳成绩。这些验证针对程序和数据保存，不构成 IQ 测量精度验证。

2026-10-21 验证结果：91 项单元测试通过；原有 8 项界面流程通过，新增的历史筛选、单条导出和移除流程单独补测通过。实际经系统文件界面保存的 JSON 已核对版本、记录数量、模块、提前结束状态和答案快照。专用模拟器原有的 24 条旧记录已完整迁移，旧数据备份与原始字节一致。
