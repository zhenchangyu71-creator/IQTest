# 实验性 IQ 估算：算法、依据与改进路径

更新日期：2026-10-22。A 组模型 `irt-heuristic-v2`、B 组模型 `irt-heuristic-form-b-v2`，对应题库版本 `practice-2026-10-22-v4`。

## 韦氏怎样得到 IQ

韦氏的计分分为项目评分、分测验原始分、按年龄常模换算的量表分，以及由指定分测验量表分之和换算的合成分。合成分包括 FSIQ。不同版本选用的分测验和换算资料不同，不能混用。

[评估发行方的计分说明](https://qglobal.pearsonclinical.com/qg/static/Product/fr_ca/WAIS-5/WAIS-5_Enter_Scores.htm)明确说明标准分采用年龄常模。[公开示例报告](https://www.pearsonclinical.ca/content/dam/school/global/clinical/us/assets/wais-5/wais-5-sample-score-report.pdf)分别展示原始分、量表分、量表分总和、合成分和置信区间。它们不能用一个未经验证的正确率公式互相替代。

将一个已标准化的能力位置 z 写成 `100 + 15z`，只是在 IQ 量尺上表示位置。难点在于如何从本题库作答得到可解释的 z。没有匹配的数据，公式本身不会创造常模或效度。

## 本项目现在计算什么

完整练习可输出 **实验性 IQ 估算（未校准）**。这是条件于初始模型假设的分数，并非正式 FSIQ，也没有证据证明比旧版公式更接近韦氏。年龄仅记录，未参与模型换算。本模型未证明对任何特定年龄群体具有 IQ 解释效力。

算法使用题目反应模型，参考[IRT 统计框架综述](https://arxiv.org/abs/2108.08604)所述的能力推断思想。本实现的部分得分与猜测结合方式是明确写出的模型选择，不代表韦氏官方计分算法。

### 二分类题

无论满分是 1 还是 2，只存在零分/满分两种选项时，采用：

```
p(满分 | θ) = c + (1-c) × sigmoid(a × (θ-b))
p(零分 | θ) = 1 - p(满分 | θ)
```

- `θ`：模型中的能力坐标。
- `b`：初始题目阈值。
- `a`：区分度参数，初始统一设为 1，可由后续拟合替换。
- 选择题 `c` 为满分选项数量 / 全部选项数量，基于均匀随机猜测假设。
- 数字自由回忆 `c=0`，不使用未展示给作答者的选项估算猜测率。这也不表示现实中的偶然答对概率严格为零。

均匀猜测是假设，不是已测得的实际猜测行为。模型不能消除选项排除、熟悉题目或外部协助等影响。

### 存在 0/1/2 三种分值的题

设两个递增阈值 `b1 < b2`，均匀猜测时非零分概率为 `cAny`，满分概率为 `cFull`：

```
p(得分至少1 | θ) = cAny  + (1-cAny)  × sigmoid(a × (θ-b1))
p(得分为2   | θ) = cFull + (1-cFull) × sigmoid(a × (θ-b2))
p(得分为1   | θ) = p(至少1) - p(为2)
p(得分为0   | θ) = 1 - p(至少1)
```

由于 `cAny >= cFull` 且 `b1 < b2`，类别概率非负且总和为 1。部分得分因此保留为独立类别，而非一律按错误或满分处理。

### 能力估计和量尺

```
p(θ | 作答) ∝ N(0,1) × ∏ p(每题得分 | θ)
θ估计 = 后验均值（EAP）
实验性IQ估算 = round(100 + 15 × θ估计)
```

实现采用步长 `0.025` 的网格积分，并以 log-sum-exp 方式稳定计算。从 `-6...6` 开始，检查边界外侧半单位的归一化质量；不低于 `1e-8` 时扩展到 `-10...10`、`-14...14`、`-18...18`。仍未收敛时拒绝输出，而不是把边界截断误当成真实结果。`N(0,1)`、100 和 15 是初始模型的坐标约定，**不是本项目人群的实测均值和标准差**。整数显示也不表示误差只有 1 分。

没有把后验区间包装成实际 IQ 置信区间：即使模型条件下的数值推断较稳定，未测得的题目参数误差、常模偏差、构念差异仍可能很大。量表分剖面的 95% 区间改由局部 Fisher 信息传播得到，并以韦氏手册的实测水平为下限；该区间只覆盖本题库内的测量误差，不包含未校准带来的系统偏差。

## 参数来源与拒绝条件

[模型参数文件](../IQTest/Resources/WechslerIQModel.json)逐题记录阈值、区分度、题号、模型版本和题库版本。初始阈值按题目内容作启发式设定，不是专业专家标定、标准化样本拟合或公开韦氏转换表。B 组使用单独的参数文件，初始值参考 A 组对应题序的种子值；这不构成题组等值或题目难度相同的证据。选择 B 组时不会使用 A 组参数计分。

- `calibrationStatus` 明确为 `heuristic`，界面始终显示“未校准”。
- 年龄不做经验加减分，不提供同龄人或全球百分位。
- 需完成全部 10 个分测验、至少 60 个项目；三题练习不输出 IQ。这是本应用的保守输出门槛，不是经过验证的测量长度。
- 超时超过全部项目的 20% 时只报告原始成绩。其余超时按既有规则计零分并提示；20% 是本应用的输出门槛，不是研究得出的效度界限。
- 存在应用前台中断项目时，项目单独标为未计分，不将缺失成绩推算成 IQ；报告保留其余题目成绩和流程记录。详见 [施测流程](ADMINISTRATION.md)。
- 题号重复/缺失、答案和分值不符、模型参数缺失、题库版本不匹配、非有限或越界参数均拒绝估算。
- 全对或全错时标出天花板/地板效应，数值不能可靠描述更极端的能力。
- 单参数模型现在输出两层能力参数：总体 θ 与各分测验的 θ。分测验各自独立估计后，向「信息加权的中心」做经验贝叶斯收缩（强度 1.5 个 θ 单位）；中心取自各分测验自身而非总体能力——总体能力在聚合后比子测验平均更极端，用它作收缩中心会把各领域拉平。分测验的标准误取该处题目集合的局部 Fisher 信息，收缩只改点估计、不改误差估计。
- 量表分剖面保存到单独的 `wechslerProfile` 字段：分测验尺度分、领域指数分、全量表分、百分位、等级描述与 95% 区间。换算结构参照韦氏标准十分法，具体见 [韦氏风格量表分换算说明](WECHSLER_STYLE_SCORING.md)。
- 实验性结果保存到单独的 `iqEstimate` 字段，包含模型版本、题库版本和未校准状态。正式 `iq`、`percentile` 字段不被填入；不混入瑞文趋势。
- 旧记录没有 `iqEstimate` 或 `wechslerProfile` 时保持原样，不用新模型偷偷重算旧成绩。

## 怎样有证据地接近韦氏

算法提供了可替换的参数层，但本轮没有真实数据拟合或精度验证。后续应分开解决题目测量、年龄标准化和韦氏分数预测：

1. **改进测量任务**：现有文字选择题不能替代实物积木、真实视觉任务、标准听觉广度或开放式言语评分。扩充能区分中高能力的题目，减少天花板效应。
   - **题目参数与真实难度脱节，多数用户会被判为低于平均**：[难度诊断脚本](ITEM_DIFFICULTY_AUDIT.py) 显示，
     按当前启发式参数，「模型定义的平均能力」（θ=0）时题库整体预期得分率为 **82.5%**，
     而韦氏常模中位数对应的原始分占比约 50%——高出 33 个百分点。
     也就是说，要被判为平均水平，使用者需要答对约 83% 的题；真实用户多数达不到，因此被系统性判为低于平均。
     根因在参数是启发式设定、未经真实数据标定，不在换算公式，也不必靠改题目来掩盖；
     修法是参数拟合与逐题难度复核。
   - **各分测验难度极不齐**：θ=0 时各分测验预期得分率的极差达 **41.4 个百分点**
     （数字广度 51% 对矩阵推理 92%）。记忆域因此系统性偏低，剖面中的「领域差异」有相当部分来自难度差异而非能力差异。
     逐题复核时应优先处理数字广度、符号编码、符号搜索三项。
   - **A/B 题组参数完全照抄**：按对应题号配对后，两组 120 项难度参数完全相同，
     而两组题目内容不同。这意味着 B 组的表面难度被设成与 A 组一致——不是等值的证据，是需要重点复核的对象。
2. **收集实际数据**：为每名参与者记录本题库逐题作答、年龄、语言、题库/模型版本；如本人有适当来源的正式测验分数，再记录其版本、语言和施测日期。没有正式成绩的样本可用于项目分析，但不能凭空产生韦氏对照效度。
   - 应用已经完整保存了逐题作答与过程记录。用 `python3 docs/calibration_export.py <导出的JSON> [输出目录]`
     可把历史导出转成拟合需要的题目表、作答表与被试表，并附带数据质量检查（缺失、超时、中断、年龄覆盖），
     无需另行设计采集格式。
3. **拟合题目参数**：检查维度结构和项目拟合，再估计阈值、区分度及适当的猜测参数。当前单一 θ 模型对 10 种任务的一维假设也必须检查；必要时采用有依据的多维模型。
4. **建立合适常模或预测关系**：按目标人群处理年龄和语言；互联网自选样本不能直接冒充总体常模。若目标是预测某一韦氏版本的分数，使用同一参与者的配对数据拟合关系，而非对照两个不相关样本的平均数。
   - **标定本项目自己的换算斜率**：借用韦氏的斜率只在「尺度分之和的离散度与韦氏题库相同」时成立，而本项目每个分测验只有 12 题，
     能力估计被显著压窄（见 [韦氏风格量表分换算说明](WECHSLER_STYLE_SCORING.md)的「标定状态与已知偏差」）。
     用真实样本做三件事：估计能力估计的可靠性相关 r（对能力估计去衰减）、实测尺度分之和的离散度、据此反推指数分与全量表分的斜率。
     [算法自检脚本](ALGORITHM_SELF_CHECK.py) 用合成被试走通了同一流程，可以直接改接真实样本。
5. **按参与者拆分训练/验证/留出测试集**：同一人的复测不能跨集合泄漏。报告偏差、MAE、RMSE、不同年龄/语言/分数段的误差和一致性；只报告高相关系数不足以证明接近。
6. **独立验证后再解释精度**：区间需要覆盖误差，量表版本差异、复测和测量噪声会限制可达到的一致性。能否达到产品目标必须通过预先确定的验证标准判断，不能承诺“无限接近”。

程序单元测试、合成作答模拟和人工设定参数只能验证代码和假设下的行为，不能替代上述实证验证。
