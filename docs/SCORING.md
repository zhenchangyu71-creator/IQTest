# 韦氏风格练习：计分与验证边界

更新日期：2026-10-21。题库版本：`practice-2026-10-21-v3`。

## 已解决的程序问题

旧版把正确率线性映射为量表分，再把量表分均值映射为 IQ，并按四个宽年龄带人为加分。这些参数没有本题库的标准化样本支持，不能称为年龄常模。旧版同时用正态分布生成“超过全球多少人”，也没有对应人群依据。

新版移除了上述人为加分与「全球排名」表述，改为借鉴韦氏的**量表分结构**呈现结果：分测验尺度分、领域指数分、全量表分，以及由正态量尺换算的百分位与等级描述。这些输出全部标注为未校准。正式 FSIQ、逐龄常模与人群百分位仍不生成；置信区间只反映本题库内的测量误差，不包含题目参数未校准带来的系统偏差。

尺度分来自按逐题参数推断的能力参数，而不是原始分查表——没有分龄常模表，无法从原始分直接得到常模化尺度分。指数分与全量表分对「尺度分之和」的换算关系参照 Pearson 官方示例报告的公开数值核对，而不是逐龄的官方换算表。

这些斜率是为韦氏题库标定的，在本项目的题目参数下会让合成分的离散度比设计意图窄约 14%（每个分测验只有 12 题，信息量不足导致能力估计被压窄）。[算法自检脚本](ALGORITHM_SELF_CHECK.py) 会持续检验这一项。具体算法、参数来源与拒绝条件见 [韦氏风格量表分换算说明](WECHSLER_STYLE_SCORING.md)；单参数能力模型的说明见 [IQ 估算说明](IQ_ESTIMATION.md)。

| 报告项 | 定义 | 可用于什么 |
| --- | --- | --- |
| 单题分数 | 预先定义的选项分值，或数字序列精确匹配分值 | 核对当前题的作答 |
| 原始分 | 单题得分相加 | 描述当前版本题库表现 |
| 题目得分率 | 原始分 / 对应满分 × 100% | 描述本组题所得分数比例 |
| 超时数 | 到达作答截止时刻的题数 | 解释未得分项目 |
| 中断题 | 失去前台后标为未计分，并从分母排除 | 描述缺失项目，不当作答错；有中断时不生成剖面 |
| 分测验尺度分 | 1...19，Mean 10 / SD 3，附 95% 估计区间 | 韦氏式分测验表现描述 |
| 领域指数分 | 领域合成分，Mean 100 / SD 15 | 领域间比较，仅限同一份剖面内 |
| 全量表分 | 全部核心分测验的合成分，Mean 100 / SD 15 | 总体描述，不等同于正式 FSIQ |
| 百分位与等级 | 正态量尺换算与韦氏式分档 | 粗略分档，不作诊断，不解释为同龄人排名 |
| 95% 区间 | 由局部 Fisher 信息传播 | 仅反映本题库内的测量误差 |
| 年龄 | 开始时的整数年龄快照 | 记录基本信息，未参与换算 |
| 逐题记录 | 题号、答案、分值、状态、用时 | 检查计分与题库问题 |

领域和分测验内容、题量、题目难度不等价。得分率雷达图展示题目表现，不具有标准化能力剖面的解释效力。复测与看过解析会改变题目熟悉度；结果页会在存在练习或历史记录时提醒。

每个分测验新增独立的不计分操作示例，用户准备好后才计时。完整记录另存流程版本、已完成示例和中断事件；这些过程改进不构成精度验证。中断项目不填补成绩，得分率仅针对其余项目；没有计分项目时不显示数值得分率。详见 [施测流程说明](ADMINISTRATION.md)。

## 题目与施测仍有哪些限制

这 240 题为本应用自编内容，分成 A/B 两组，没有作为正式韦氏题本使用的依据。两组尚未通过等值验证，分数不宜直接比较。积木与视觉拼图目前主要是文字/符号选择题，不能等同于实物操作或正式视觉任务。数字广度使用屏幕视觉刺激，自由输入虽减少了选择题识别线索，仍不同于标准听觉呈现与口头回答。言语题采用选项部分得分，不替代专业人员对开放回答的评分。加工速度限时也没有本应用的媒介等值研究支持。

因此，补齐解析、减少歧义、保证计时代码准确，只能提高本练习的题目质量与程序可核对性，不能单独证明智商测量精度。

## 若要提供有依据的 IQ

需要由合适的专业团队完成以下工作，再按该版本技术手册实现计分，而不是补一组经验公式：

1. 明确量表版本、语言、文化和目标人群；取得适当授权的题目、评分与施测材料。成人与儿童版本不能共用一套任意年龄修正。
2. 明确施测媒介与标准程序，包括指导语、示例题、起点、回溯、停测、限时、开放回答评分、施测人员要求及异常情况处理。
3. 对本应用实际题目和媒介收集代表性标准化样本，进行项目分析与信效度验证；如采用正式量表的数字化呈现，还需有适当的等值性依据。
4. 使用适配版本与人群的原始分到年龄量表分、量表分合成到指数/FSIQ 的转换资料。不得将 WAIS/WISC 的表格用于不相同的自编题。
5. 有适配的测量误差或估计误差证据后再报告置信区间。区间宽度不能自行指定为“±5 分”，也不能用单题答对率的抽样误差替代 IQ 的测量误差。
6. 为超出适用年龄、缺项、非标准施测、语言限制及复测建立解释规则。代码测试之外，进行独立专业审查。
