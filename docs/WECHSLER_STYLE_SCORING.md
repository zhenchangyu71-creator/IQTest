# 韦氏风格量表分换算说明

更新日期：2026-10-22。题库版本：`practice-2026-10-22-v4`。模型版本：`irt-heuristic-v2`。

## 目的与边界

本应用没有人群常模，也没有使用任何韦氏原始分换算表，因此不可能产出正式韦氏 IQ。
但可以借鉴韦氏的**量表分结构**，让一次练习的结果按韦氏熟悉的读法呈现：尺度分 → 指数分 → 全量表分 → 百分位 → 等级描述。

这样做解决的是**可读性与可比性**，不是测量精度。输出必须始终理解为「本次练习在本题库上的相对表现」，
不能解释为同龄人排名，不能用于诊断，也不能声称接近正式韦氏结果。

| 报告项 | 定义 | 可用于什么 |
| --- | --- | --- |
| 原始分 | 单题得分相加 | 核对当前题库的表现 |
| 尺度分 | 1...19，Mean 10 / SD 3 | 韦氏式分测验表现描述 |
| 标准九分 | 1...9 | 尺度分的粗粒度表述 |
| 指数分 | 领域合成分，Mean 100 / SD 15 | 领域间比较（同一份剖面内） |
| 全量表分 | 全部核心分测验的合成分，Mean 100 / SD 15 | 总体描述 |
| 百分位 | 由正态量尺换算 | 相对位置的近似表述 |
| 等级描述 | 韦氏式分档 | 粗略分档，不作诊断 |
| 95% 区间 | 由 Fisher 信息传播 | 仅反映本题库内的测量误差 |

## 换算链路

### 第 1 步：能力参数（题目层）

沿用既有的单参数 IRT 模型。每题有难度阈值（部分得分题两个递增阈值）与区分度，
选择题的均匀猜测作为得分下限假设，自由回忆题不设猜测下限。

- **总体能力 θ**：全部项目在后验上的期望值，先验 N(0, 1)。先验是模型坐标约定，不是人群分布。
  仅用于记录与单参数模型输出，**不参与分测验能力估计**。
- **分测验能力 θ<sub>**：该分测验 12 题在后验上的期望值，先验同为 N(0, 1)。
- **经验贝叶斯收缩**：各分测验独立估计后，向「信息加权的中心」轻微收缩，收缩强度 1.5 个 θ 单位。

  中心取自各分测验自身的估计（按 Fisher 信息加权），而不是总体能力。这一点很关键：
  总体能力由全部项目聚合而来，在后验上比子测验平均更极端（答对所有题时总体 θ 约 2.7，
  而各分测验平均只有约 1.05）。若用总体能力作收缩中心，所有分测验都会被拉向同一个极端值，
  领域差异会完全消失——例如言语题全对、其余全错时，言语指数分会被压到 53 分。

  以分测验自身的估计作中心则能保留差异：同一场景下言语指数分 94 分、知觉指数分 50 分。

### 第 2 步：尺度分（分测验层）

```
尺度分 s = clamp(round(10 + 3 × θ_sub), 1, 19)
```

韦氏采用标准十分法：尺度分 Mean 10、SD 3、取值 1...19。这里用能力参数代替原始分查表，
因为没有分龄常模表，无法从原始分直接得到常模化尺度分。

### 第 3 步：合成分（指数层与全量表层）

官方韦氏的机制是「分测验尺度分之和 → 按龄查表 → 合成分」。没有分龄表时，用线性关系替代查表：

| 换算 | 公式 | 参数来源 |
| --- | --- | --- |
| 指数分（2 个分测验） | `100 + 2.75 × (Σs − 20)` | 由 Pearson 官方示例报告反推，五个指数的拟合误差均 ≤ 1.5 分 |
| 全量表分（10 个核心分测验） | `100 + 0.72 × (Σs − 100)` | WAIS-IV 十个核心分测验结构的线性化关系 |
| 全量表分（7 个主分测验） | `100 + 0.96 × (Σs − 70)` | WAIS-5 / WISC-V 七个主分测验结构的线性化关系 |

斜率不同是必然的：分测验越多，尺度分之和的离散越大，折算到 IQ 的斜率越小。
这也是「1 个尺度分 = 1 个 IQ 分」这一直觉错误的来源。

### 第 4 步：百分位与等级

```
合成分百分位 = Φ((合成分 − 100) / 15)
尺度分百分位 = Φ((尺度分 − 10) / 3)
```

该换算已用 Pearson 两份官方示例报告实测验证，误差小于 0.3 个百分点
（尺度分 s=11→P63、s=14→P91、s=7→P16；合成分 114→P82、79→P8、94→P34）。

等级描述沿用韦氏官方分档：

| 合成分 | 描述 | 尺度分 | 描述 |
| --- | --- | --- | --- |
| ≥130 | 极高 Very Superior | ≤7 | 很低 Very Low |
| 120–129 | 高 Superior | 8–9 | 较低 Below Average |
| 110–119 | 中高 High Average | 10–11 | 平均 Average |
| 90–109 | 平均 Average | 12–13 | 较高 Above Average |
| 80–89 | 中低 Low Average | ≥14 | 很高 Very High |
| 70–79 | 临界 Borderline | | |
| ≤69 | 极低 Extremely Low | | |

### 置信区间

标准误由**局部 Fisher 信息**传播，而不是指定一个「±5 分」：

```
分测验 SE = 1 / sqrt(Σ 该分测验项目在 θ 处的 Fisher 信息)
指数分 SEM = 2.75 × sqrt(Σ SE²)
全量表分 SEM = 0.72 × sqrt(Σ SE²)
95% 区间 = 分数 ± 1.96 × SEM
```

3PL 项目的 Fisher 信息为 `I = a²(p−c)²(1−p) / ((1−c)²·p)`；部分得分题按嵌套 Rasch 模型处理，
「至少得 1 分」与「得满分」两层信息相加。信息趋近于零（天花板或地板）时区间不予报告。

分测验的标准误取该分测验在自身 θ 处的局部 Fisher 标准误。收缩只改点估计、不改误差估计，
避免因为数据向中心靠拢而虚假收窄区间。

**分测验尺度分也带区间**。每个分测验只有 12 题，尺度分的标准误是 3 × SE(θ)，
通常有 1.5–3 分，对应 95% 区间宽达 ±5–9 分。报告里必须同时给出区间：
不带区间的十个尺度分并排列出，会诱导用户做精细比较，而这种比较超出了数据能支撑的精度。
两个分测验的差异若落在各自区间内，不代表能力高低。

自编题库的信度未经验证，因此 SEM 取 Fisher 传播值与韦氏手册实测值的**较大者**：
指数分下限对应 95% 半宽 ±7 分，全量表分下限对应 ±5 分。区间**只反映本题库内的测量误差**，
不包含题目参数未校准带来的系统偏差——那部分无法用本应用的数据估计。

区间上下界同样限制在合成分可解释范围（50...145）内；半宽超过 30 分时区间不再作为有效区间展示。

实际表现（独立复算，与韦氏手册实测水平对照）：

| 作答情形 | 全量表分 | 百分位 | 95% 区间 | 全量表分 SEM |
| --- | --- | --- | --- | --- |
| 全部答对 | 124 | P95 | 117–131 | 3.5 |
| 约八成正确 | 99 | P47 | 94–104 | 2.6 |
| 随机作答 | 59 | P0 | 54–64 | 2.8 |
| 全部答错 | 50（下限） | P0 | 50–57 | 3.4 |

韦氏手册的全量表分 SEM 约为 3.0（95% 区间 ±5 分），上表与之接近。

## 标定状态与已知偏差

换算参数的唯一真源是 [`ScoringCalibration.json`](../IQTest/Resources/ScoringCalibration.json)：
生产代码用其中的同名常量，`docs/` 下的分析脚本直接读它，
单元测试断言两边一致——避免分析脚本与生产代码各持一份副本、各改各的。

斜率 2.75 与 0.72 是**为韦氏题库标定**的：它们的推导前提是「十个分测验的尺度分之和，标准差约 20.8」。

用 [算法自检脚本](ALGORITHM_SELF_CHECK.py) 在本项目当前的题目参数下生成 200 个合成被试做检验，得到：

| 量 | 本项目实测 | 斜率推导的前提 |
| --- | --- | --- |
| 能力估计的标准差 | 0.76 | 1.00 |
| 尺度分的标准差 | 2.28 | 3.00 |
| 十个分测验尺度分之和的标准差 | 23.2 | 20.8 |
| 折算出的合成分标准差 | 16.6 | 15.0 |

**后果：当前输出的合成分离散度比设计意图宽约 11%。** 同样能力的两个人，本系统给出的指数分与全量表分差异大于韦氏。

原因不是斜率取错，而是**斜率仍是为扩充前的题库借用的**。题库扩充后，离散度从当初的偏窄 16% 变成偏宽 11%。

这里有两个量，不要混用：
- **能力估计的标准差 0.76** —— 估计值的分散程度。经验贝叶斯收缩把能力位置向中心压缩
  （这是设计如此，为了压噪），换算成量表分时需要把这个压缩还原回来，这就是去衰减。
- **能力估计与真实能力的相关** —— 测量准不准。用合成被试测得约 **0.96**（题池全用 24 题/分测验时 0.969），
  与韦氏水平相当。用估计值的离散度代替它会得出「模型误设反而更准」的反直觉结论。

韦氏的分测验原始分跨度大得多（积木 67 题、词汇 40 题、算术 36 题），
且查表本身已经吸收了信度影响，不存在这个衰减。

**尚未实施的修正**：对能力估计做去衰减（乘 1/r），再按本项目实测的 Σs 离散度重新标定斜率。
自检脚本给出的建议值为：能力估计的可靠性相关 r ≈ 0.76（去衰减因子 1.32），
去衰减后建议的全量表分斜率约 **0.49**（现借用 0.72）、指数分斜率约 **1.98**
（各域 1.58–2.30，现借用 2.75）。

**这些建议值没有实施。** 它们来自合成被试，即用模型验证模型：模型参数若有误，
去衰减因子会被高估，去衰减后的放大也就过头。

用真实作答数据标定的流程已经铺好：
`calibration_export.py` 把历史导出转成拟合数据集并做质量检查，
`calibrate_slopes.py` 复用自检的同一套估计流程但换成真实作答，
实测离散度后反推「让合成分标准差回到 15」的斜率。
该脚本在合成被试下与自检给出高度一致的结果：扩充前的题库上是 0.512 对 0.506、
1.667/1.728/2.202/2.458 对 1.654/1.733/2.231/2.318；扩充后的题库上是 0.492 对 0.506、
1.584/1.735/2.299/2.290 对 1.654/1.733/2.231/2.318。两套独立实现在两个不同题库上
给出一致的建议斜率，说明标定方法本身是稳健的。

在此之前，所有输出继续标注为「未校准」。

剖面记录里带 `scoringVersion` 字段（当前为 `wechsler-style-borrowed-v1`）。斜率一旦用真实样本
重新标定，取值随之改变，历史记录据此可以区分不同标定下的分数，避免新旧数值被混为一谈。

## 几套换算方案的对比

[对比脚本](ALGORITHM_COMPARISON.py)在同一批作答上并列四套方案。注意：它回答的是「各套分别给出什么」，
不是「哪一套更准」——后者需要与正式量表的配对数据，本项目没有。

全量表分（韦氏合成分的可用范围是 55–145）：

| 场景 | 旧单参数模型 | 早期收缩版 | 当前剖面 | 重新标定后（未实施） |
| --- | --- | --- | --- | --- |
| 全部答对 | 149 | 145 | 135 | 140 |
| 约八成正确 | 99 | 97 | 99 | 98 |
| 约五成正确 | 69 | 52 | 65 | 60 |
| 随机作答 | 33 | 50 | 50 | 50 |
| 全部答错 | **15** | 50 | 50 | 50 |
| 言语全对、其余全错 | 43 | 51 | 63 | 57 |

领域指数分（言语 / 知觉 / 记忆 / 速度）：

| 场景 | 早期收缩版 | 当前剖面 | 重新标定后（未实施） |
| --- | --- | --- | --- |
| 全部答对 | 145 / 145 / 145 / 145 | 138 / 133 / 133 / 128 | 136 / 131 / 131 / 126 |
| 约八成正确 | 97 / 84 / 106 / 103 | 100 / 86 / 106 / 103 | 100 / 87 / 105 / 103 |
| 约五成正确 | 50 / 50 / 78 / 67 | 56 / 50 / 86 / 78 | 58 / 51 / 87 / 79 |
| 随机作答 | 50 / 50 / 50 / 50 | 50 / 50 / 53 / 59 | 50 / 50 / 56 / 61 |
| 全部答错 | 50 / 50 / 50 / 50 | 50 / 50 / 53 / 50 | 50 / 50 / 56 / 53 |
| 言语全对、其余全错 | **86 / 50 / 50 / 50** | **108 / 50 / 59 / 64** | 108 / 50 / 61 / 66 |

三点读法：

1. **早期收缩版是缺陷版本**。它把分测验向总体能力收缩，结果是领域差异被抹平——
   全部答对时四个领域全部撞上 145，言语全对时言语只拿到 86（其余领域 50）。
   分测验各自独立估计后才有区分度（言语 108 对其余 50 附近）。
2. **旧单参数模型会跑出韦氏不可能报告的值**。全部答错得 15，低于合成分可用下限 55；
   随机作答（33）与全部答错（15）几乎无法区分。当前剖面有明确的量表分钳制与合成分上下限。
3. **重新标定只改变离散度，不改变任何相对关系**。它是「以 100 为中心的线性放大」，
   因此分数的排序、领域结构、显著性判断都不受影响，只是不再把差异放大 11%。

另需注意「约五成正确」只得到 65 分。按当前启发式参数，「模型定义的平均能力」（θ=0）时题库整体预期得分率是
**82.5%**（[难度诊断脚本](ITEM_DIFFICULTY_AUDIT.py)），比韦氏常模中位数对应的原始分占比（约 50%）高 32.5 个百分点——
要被判为平均水平，使用者得答对约 82%。真实用户多数达不到，因此被系统性判为低于平均。
根因是题目参数与真实难度脱节，不是换算公式的问题；见 [IQ 估算说明](IQ_ESTIMATION.md) 的改进路径。

### 得分率对照

剖面同时记录两件事：**本次作答的实际得分率**，以及**模型定义的平均能力（θ=0）时题库整体的预期得分率**（约 82%）。

两者并列在结果页上，因为只有对照才能说清分数的来源：读者看到"65 分"时无从判断
是作答偏弱，还是题库刻度偏严。有了对照可以直接看到「本次答对 60%，而本题库平均水平的预期是 82%」——
分数反映的是相对本题库的位置，不是绝对水平。

这个对照同时暴露了当前最实质的问题：按现有参数，要被判为平均水平需要答对约 82%，
多数真实用户达不到，因此会被系统性判为低于平均。根因是题目参数未经真实数据标定。

### 分测验难度基准

每个分测验在 θ=0（模型定义的平均能力）时的预期得分率，反映它在当前题目参数下有多难：

| 分测验 | θ=0 预期得分率 |
| --- | --- |
| 数字广度 | 51% |
| 符号编码 | 73% |
| 算术 | 82% |
| 类同 | 90% |
| 积木 / 矩阵推理 | 92% |

极差达 **41.4 个百分点**。结果页会列出基准低于 70% 的分测验并提示：这些分测验的尺度分偏低
是题目难度造成的，不宜直接解读为能力较弱。没有这条提示，使用者很容易把
「数字广度一贯更难」误读成「数字记忆能力较弱」。

这条基准同样来自启发式参数，未经实测标定——它说明的是「当前模型认为这些题更难」，
不是「这些题在真实人群中的实际难度序」。

**雷达图按基准归一。** 原始得分率因各分测验难度不齐而不可横向比较：数字广度 50% 与
矩阵推理 90% 看起来差很多，但两者的基准分别是 51% 与 92%，实际相对表现几乎相同。
结果页的雷达图因此按基准归一，外圈表示「达到该分测验的本题库平均水平」，超过基准记为满格。
单项练习页的雷达图没有基准数据，仍显示原始得分率。

## 领域两两比较

领域指数分之间做两两比较，判断差异是否达到 95% 置信水平。两个领域由互不相交的题目构成，
其估计误差可视为独立，因此差异的联合标准误为两者标准误的平方和开根：

```
差异显著 ⟺ |指数分之差| > 1.96 × √(SE₁² + SE₂²)
```

韦氏手册使用的固定差值门槛（如 12 分）是针对其自身常模与信度标定的，
本项目的误差结构不同，直接套用没有依据，因此改用上述按实际误差计算的判断。

这是本次结果的统计差异，不是能力诊断。

## 与正式韦氏的差异

1. **没有分龄常模**。官方换算表按年龄段分表；本应用对所有年龄使用同一套换算关系。
2. **没有原始分→尺度分的常模表**。官方查表非线性且随年龄变化；本应用从能力参数出发。
3. **题目参数未拟合**。区分度全部为 1.0，阈值由启发式设定。
4. **A/B 题组未等值**。两组的模型阈值完全相同，分数不可直接比较。
5. **媒介不等值**。积木、视觉拼图、矩阵均为文字/符号题，不能替代实物操作与视觉任务。
6. **数字广度是视觉呈现 + 自由输入**，不同于标准听觉呈现 + 口头回答。
7. **随机作答与低能力在模型下不可区分**。选择题的猜测下限使「乱猜」与「能力极低」的观测几乎等价，
   两者都会落到量表下端（全量表分约 50）。这与韦氏原始分查表的行为一致（乱猜的原始分接近常模低分位），
   但也意味着本算法分不清「不会做」和「随便选」。题目区分度未经拟合，此处尤其明显。

因此本输出**不是** WAIS/WISC，也不与之等值，不能用于任何需要正式测验结论的场合。

## 质量门槛

与既有估算一致，任一不满足则不生成剖面，只报告原始成绩：

- 完成全部 10 个分测验，且至少 60 题；
- 无中断项目（有中断的题不填补得分，也不计入分母）；
- 超时比例不超过 20%（超时按零分处理）；
- 题库版本与模型版本严格匹配。

见 [计分与验证边界](SCORING.md) 中「若要提供有依据的 IQ」一节。简要说，需要标准化样本、
